# MA DAVVERO? — Instagram Autopilot

Sistema AI per la gestione autonoma di un profilo
Instagram italiano dedicato alle curiosità scientifiche.

## Obiettivo
Automatizzare ricerca, verifica delle fonti,
creazione Reel, caroselli, programmazione
e analisi dei risultati.

## Tecnologie
Python, FastAPI, OpenAI API, Supabase, FFmpeg.

## Stato
Progetto in fase di sviluppo.
